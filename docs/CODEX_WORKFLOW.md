# Codex Workflow

## Recommended loop

1. Use `/studio` to define the remix inputs.
2. Open `/preview` and review the generated MVP pack.
3. Copy the Codex build prompt from the preview page.
4. Use Codex to implement the chosen concept or extend the demo.
5. Run `npm run build` before shipping.

## What Codex gets from the preview

- product framing
- target users
- must-have and stretch features
- API data flow narrative
- template and style direction
- deployability constraints
